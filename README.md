# КБЖУ Трекер — Мобильный и десктопный дневник питания

Простой, красивый и удобный веб-трекер КБЖУ (Калории, Белки, Жиры, Углеводы) с шаблонами блюд, отслеживанием веса (+0.1 кг) и календарем статистики. Работает полностью автономно в браузере!

## 🚀 Публикация на GitHub Pages

Чтобы ваш сайт открывался по адресу `https://<ваш-логин>.github.io/kbju-tracker/`:

1. Откройте ваш репозиторий на [GitHub](https://github.com/Default00xD/kbju-tracker).
2. Зайдите в папку `kbju-tracker` и перетащите мышкой файлы из вашей локальной папки:
   - `index.html`
   - `css/styles.css`
   - `js/app.js`
3. Убедитесь, что в **Settings -> Pages** выбрана ветка `main`.
